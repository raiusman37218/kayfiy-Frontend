# KAYFIY — social logo pack

Generated from the brand art in `public/` by `node scratch/make-social-logos.mjs`.
Re-run that script if the logo ever changes.

## Profile pictures (1024 × 1024)

Platforms crop these to a circle, so the logo sits inside the safe area.

| File | Use it for |
|---|---|
| `profile-blush.png` | Default. Soft pink ground, matches the brand. |
| `profile-cream.png` | When the pink reads too warm next to a white feed. |
| `profile-maroon.png` | Dark variant — stands out in a light feed, good for WhatsApp Business. |

## Cover / header

| File | Use it for |
|---|---|
| `cover-1500x500.png` | Facebook, X and LinkedIn headers. Logo is centred, so side-cropping on mobile is safe. |

## Transparent lockups

Put these over photos or your own artwork. No background baked in.

| File | Use it for |
|---|---|
| `logo-maroon-transparent.png` | Over light backgrounds. |
| `logo-cream-transparent.png` | Over dark or busy photos. |
| `logo-horizontal-maroon.png` | Wide lockup, light backgrounds — invoices, letterheads. |
| `logo-horizontal-cream.png` | Wide lockup, dark backgrounds. |

## Brand colours

- Maroon `#7A2A3D` — primary
- Blush `#FBD9DE` — soft ground
- Cream `#FCF9F3` — light ground
- Antique gold `#B08D4F` — accent only, never for body text
